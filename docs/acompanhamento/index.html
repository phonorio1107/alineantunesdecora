As 12 fases, em linguagem simples

Cada fase tem uma lista de itens no arquivo PROJETO.md. Uma fase só termina quando todos os itens estão feitos ou foram dispensados por você.

Palavras que aparecem no projeto

Protótipo
Uma versão de mentira do sistema, com números de exemplo, para ver e clicar antes de construir de verdade.
Banco de dados
Onde ficam guardadas todas as informações: clientes, eventos, entradas e saídas. É uma grande planilha organizada e protegida.
Supabase
O serviço que guarda o banco de dados e cuida do login. Fica num servidor em São Paulo.
Cloudflare
O serviço que coloca o sistema no ar, no endereço app.alineantunesdecora.com.br.
GitHub e repositório
Onde fica guardado o código do sistema, com o histórico de cada mudança.
Branch
Uma cópia de trabalho do código. A main é a versão oficial; a dev é onde se testa antes.
Migração
Um arquivo com as instruções para montar ou mudar o banco de dados. Toda mudança passa por uma, nunca na mão.
RLS (segurança por linha)
A regra dentro do banco que decide quem vê o quê. É o que impede a assistente de ver o financeiro, ou outra empresa de ver os dados da Aline.
Teste de isolamento
Um teste automático que tenta “invadir” os dados de outra empresa e de outros perfis. Se conseguir, o teste falha e avisa.
Verificação em duas etapas
Além da senha, um código no celular para entrar nas contas. Se a senha vazar, ninguém entra sem o celular.
