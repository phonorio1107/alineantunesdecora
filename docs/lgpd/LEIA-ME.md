# Documentos de LGPD (rascunhos para o advogado)

**Rascunhos escritos pelo Claude em 30/10/2026. Não são parecer jurídico.** Antes de publicar ou assinar, um advogado precisa revisar, principalmente bases legais, prazos de guarda e a cláusula de operador.

| Arquivo | Para quem | Onde vai |
|---|---|---|
| `politica-de-privacidade.md` | Clientes, alunas e usuários do sistema | Link no sistema (tela de entrar), no contrato e no site |
| `termos-de-uso.md` | Quem usa o sistema (Aline e equipe) | Link no sistema, aceito no primeiro acesso |
| `suboperadores.md` | Aline (controladora) | Anexo do contrato Pedro × Aline |
| `plano-de-incidente.md` | Pedro | Uso interno; resumo no contrato |

Campos entre colchetes, como `[CNPJ]`, ficam para preencher.

Pendências que dependem de terceiros:
- **Contador da Aline:** confirmar os prazos de guarda (fiscal de 5 anos, e se vale para todos os dados do cliente).
- **Advogado:** bases legais, transferência internacional (Cloudflare e GitHub), cláusula de operador e foro.
- **Aline:** nome e contato do encarregado (pode ser ela mesma) e o canal para pedidos dos titulares.
