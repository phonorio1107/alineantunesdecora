# Termos de uso do sistema · Aline Antunes Decora

> **RASCUNHO para revisão de advogado.** Versão de 30/10/2026. Para quem usa o sistema (proprietária e equipe).

## 1. O que é
Sistema de gestão financeira e de eventos da Aline Antunes Decora, desenvolvido e mantido por Pedro Hoffman.

## 2. Acesso
- O acesso é pessoal e só por convite da proprietária. Não compartilhe a sua senha.
- Use uma senha de pelo menos 10 caracteres, que você não use em outro lugar.
- A proprietária pode mudar o seu perfil ou retirar o seu acesso a qualquer momento.
- Avise a proprietária imediatamente se perder o celular, suspeitar que alguém usou a sua conta ou vir algo estranho.

## 3. Uso permitido
- Use o sistema só para o trabalho da Aline Antunes Decora.
- Não copie, exporte ou envie dados de clientes para fora do sistema sem autorização da proprietária.
- Não tente acessar telas ou dados que o seu perfil não mostra.

## 4. Dados pessoais
Os dados de clientes e alunas são tratados conforme a **Política de privacidade**. Quem usa o sistema deve seguir essa política e guardar sigilo, inclusive depois de deixar a equipe.

## 5. Registros
O sistema registra quem criou ou alterou cada informação, e quando, para segurança e conferência. Esses registros não guardam o conteúdo de dados pessoais.

## 6. Disponibilidade
O sistema roda em serviços de terceiros (Supabase e Cloudflare) e pode ficar fora do ar por manutenção ou falha deles. Há backup diário; no pior caso, perdem-se as alterações das últimas 24 horas.
